# Streamlit 수험생 학습 관리 & OMR 채점 포털

고등학교 수험생들을 위한 평가원 기출문제 자동 채점, 일정 관리(캘린더) 기능이 통합된 Streamlit 웹 애플리케이션입니다.

---

## 1. 프로젝트 소개 (Introduction)
- 개발 배경: 종이 문제지와 정답지를 따로 대조하며 채점하는 번거로움을 줄이고, 학습 일정과 OMR 채점 과정을 한곳에서 효율적으로 관리하기 위해 제작했습니다.
- 주요 타겟: 수능 및 평가원 모의고사를 준비하는 수험생

---

## 2. 주요 기능 설명 (Key Features)
1. 평가원 기출 OMR & 자동 채점
   - 시행 회차 및 세부 선택 과목별 원본 문제지(PDF) 링크 연결
   - 키보드 숫자 입력 및 `Tab` 키 이동을 지원하는 OMR 입력 폼
   - 제출 즉시 정답과 대조하여 최종 점수 및 오답(내가 쓴 답, 정답) 출력
2. 일정 캘린더
   - 캘린더 기반 월/주/일 뷰
   - 캘린더 날짜 칸 클릭 시 팝업을 통한 간편한 일정 등록 및 색상 지정

---

## 3. 사용법

앱 실행 후 사이드바에서 원하는 메뉴를 선택

캘린더 페이지: 날짜 칸을 클릭해 팝업창을 띄우고 일정을 간편하게 추가

기출 OMR 페이지: 시험 시행 회차와 과목을 선택한 뒤, 우측 OMR 입력 칸에 키보드로 답을 입력하고 [OMR 제출 및 자동 채점하기] 버튼을 누르기
